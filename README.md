# Portfolio de Douraid Dridi

Un portfolio moderne et interactif créé avec Next.js, TypeScript, Tailwind CSS et Framer Motion.

## 🚀 Fonctionnalités

- ✨ Design moderne avec animations fluides
- 🌙 Mode sombre/clair
- 📱 Entièrement responsive
- 🎨 Effets de particules en arrière-plan
- 🎯 Navigation fluide avec scroll
- 💫 Animations au scroll (Intersection Observer)
- 🎭 Glass morphism et effets de glow
- 🔗 Liens sociaux et contact

## 🛠️ Technologies utilisées

- **Next.js 14** - Framework React
- **TypeScript** - Typage statique
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **React Icons** - Icônes
- **React Intersection Observer** - Animations au scroll

## 📦 Installation

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Build pour la production
npm run build

# Démarrer le serveur de production
npm start
```

Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## 🎨 Personnalisation

Vous pouvez facilement personnaliser :
- Les couleurs dans `tailwind.config.js`
- Le contenu dans chaque composant
- Les animations dans les composants Framer Motion
- Les effets de particules dans `ParticleBackground.tsx`
